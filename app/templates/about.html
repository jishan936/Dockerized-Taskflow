Settings & About

How TaskFlow is built and how it runs.

What is TaskFlow?

TaskFlow is a task manager built as a Docker learning project. Every task and every number on the dashboard comes from a PostgreSQL database.

There is a single user and no login. The name in the welcome heading comes from the APP_USER_NAME setting in your .env file.

Technology stack

  • HTML, CSS, JavaScript and Bootstrap 5
  • Python Flask with Flask-SQLAlchemy
  • PostgreSQL 16
  • Docker and Docker Compose
  • Git, GitHub and GitHub Actions
  • Pytest

How a request travels

  1. The browser sends a request to Flask on port 5000.
  2. Gunicorn passes it to a Flask route, which validates the data.
  3. SQLAlchemy sends SQL to the db container over the Docker network.
  4. PostgreSQL stores the data in a named volume, so it survives restarts.

Settings

Configuration lives in environment variables, not in the code:

  • SECRET_KEY for Flask security
  • POSTGRES_* for database credentials
  • APP_USER_NAME and APP_PORT for the app
